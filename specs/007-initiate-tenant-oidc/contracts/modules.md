# Affected modules and contract changes

Planned implementation only. Private children are imported by their owning parent; runtime/tests use public
parents. The feature's always-empty session boundary is a real consumer contract, not a fake authenticated session.

| Module                                                                              | Current contract                                                                     | Planned change                                                                                                                                                                                                                                              | Durable test decision                                                                                                                                         |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/lib/session.ts` (new)                                                          | Absent                                                                               | Minimal session-presence capability, e.g. `SessionService.hasSession(): Effect<boolean>`, whose production implementation always reports false. No stored identity, cookie parser, store or request tenant dependency.                                      | Test the root consumer's denial/delegation in real no-session worlds; do not add a stand-alone constant-false test or claim complete session lookup.          |
| `src/app/(app)/page.tsx`                                                            | Reads tenant and renders welcome page                                                | Check session first; absence redirects to `/auth/login` before tenant lookup or protected rendering. No positive-session rendering is implemented here.                                                                                                     | Consumer property over usable/unusable tenants and supplied cookies; actual HTTP must show a first-hop 307 even when login will later fail tenant resolution. |
| `src/app/(app)/layout.tsx`                                                          | Eager tenant read before returning children                                          | Remove eager request-tenant read from this enclosing shell. Do not use layout-only guarding as evidence that child consumers cannot execute.                                                                                                                | Production HTTP and a meaningful entry test detect remaining eager reads; no test that merely counts internal calls.                                          |
| `src/app/auth/login/page.tsx` (new)                                                 | Absent                                                                               | Public server page resolves tenant through preparation, preserves ordinary 404/500 UI/status, automatically redirects to selected provider, or uses existing public sign-in failure page.
